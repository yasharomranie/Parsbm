# قالب اختصاصی ماشین‌های بادی پارس

قالب وردپرسی اختصاصی و کاملاً استاندارد برای **پارس بلومولدینگ** (Pars Blow
Molding Technology) — تبدیل‌شده از نسخه استاتیک سایت (`index.html`,
`category.html`, `post.html`, `faq.html`, `search.html`, `404.html`) بدون
هیچ تغییری در ظاهر، اما با محتوای کاملاً داینامیک و قابل مدیریت از پیشخوان
وردپرس.

- **نام قالب:** قالب اختصاصی ماشین‌های بادی پارس
- **نویسنده:** یاشار عمرانی
- **نسخه:** 1.0

## نصب

1. کل پوشه `wp/` را (با همین نام یا نامی مثل `parsbm-airmachines`) در مسیر
   `wp-content/themes/` وردپرس خود کپی کنید.
2. از پیشخوان وردپرس، بخش **نمایش (Appearance) › پوسته‌ها** بروید و قالب
   «قالب اختصاصی ماشین‌های بادی پارس» را فعال کنید.
3. در همان لحظه فعال‌سازی، قالب به‌صورت خودکار محتوای پیش‌فرض را می‌سازد
   (دسته‌های محصول، ۱۸ مدل دستگاه، اسلایدهای هیرو، ۵ خدمت، ۸ نمونه محصول،
   ۲۱ سوال متداول در ۶ دسته، یک مقاله نمونه و صفحه سوالات متداول) — دقیقاً
   همان محتوایی که در نسخه استاتیک وجود داشت. این کار فقط یک‌بار انجام
   می‌شود و تمام محتوا بعد از آن از پیشخوان قابل ویرایش/حذف/جایگزینی است.
4. از **نمایش › منوها**، منوهای «منوی اصلی»، «نوار پایین موبایل» و «فوتر -
   دسترسی سریع» به‌صورت خودکار ساخته و به محل‌های درست نسبت داده شده‌اند.
5. یک لوگوی سفارشی از **نمایش › سفارشی‌سازی › لوگوی سفارشی** آپلود کنید
   (اختیاری — در غیر این صورت از آیکون پیش‌فرض پارس استفاده می‌شود).

## مدیریت محتوا

| بخش سایت | محل مدیریت در پیشخوان |
|---|---|
| اسلایدر هیرو (خانه و هر دسته محصول) | پوست‌تایپ «اسلایدهای هیرو» |
| مدل‌های دستگاه | پوست‌تایپ «دستگاه‌ها» + طبقه‌بندی «دسته‌های محصول» |
| مقالات (صفحه تک‌پستی مثل راهنمای خرید) | نوشته‌های استاندارد وردپرس (Posts) |
| سوالات متداول | پوست‌تایپ «سوالات متداول» + طبقه‌بندی «دسته‌های سوال» |
| خدمات ویژه | پوست‌تایپ «خدمات» |
| نمونه محصولات | پوست‌تایپ «نمونه محصولات» + طبقه‌بندی «نوع نمونه» |
| اطلاعات تماس، شبکه‌های اجتماعی، متن‌های ثابت (درباره ما، بنرهای CTA، نوار اعتماد) | **نمایش › سفارشی‌سازی › تنظیمات قالب پارس** |
| منوهای ناوبری (دسکتاپ، مگامنو، کشوی موبایل، نوار پایین، فوتر) | **نمایش › منوها** |
| دیدگاه‌های مقالات | مدیریت دیدگاه‌ها (Comments) — کاملاً استاندارد وردپرس |

### نکات فنی مگامنو
برای اضافه‌کردن آیکون به هر زیرمنوی «محصولات»، در ویرایش‌گر منو یک کلاس CSS
به شکل `mega-icon-i-NAME` وارد کنید (مثل `mega-icon-i-bottle`) — شناسه
آیکون‌ها را در فایل `template-parts/icon-sprite.php` می‌بینید. برای پهن‌کردن
یک آیتم در کل عرض مگامنو، کلاس `mega-full-width` را هم اضافه کنید.

### نکات فنی نوار پایین موبایل
هر آیتم منوی «نوار پایین موبایل» با دو کلاس مشخص می‌شود: `bn-icon-i-NAME`
برای آیکون و `bn-key-KEY` برای این‌که هر قالب صفحه بداند کدام آیتم باید
روشن (active) باشد.

## ساختار فایل‌ها

```
wp/
├── style.css              سربرگ شناسایی قالب (Theme Name/Author/Version)
├── functions.php          راه‌انداز قالب
├── header.php / footer.php هدر و فوتر مشترک
├── front-page.php         صفحه اصلی
├── taxonomy-machine_category.php   آرشیو هر دسته محصول (با صفحه‌بندی واقعی)
├── archive-machine.php    آرشیو کلی دستگاه‌ها (fallback)
├── single.php / single-machine.php  تک‌مقاله / تک‌دستگاه
├── page-faq.php           قالب صفحه «سوالات متداول»
├── search.php / 404.php   جستجوی سراسری / صفحه ۴۰۴
├── comments.php           دیدگاه‌های واقعی وردپرس
├── inc/                   CPTها، متاباکس‌ها، سفارشی‌ساز، واکرهای منو، توابع کمکی
├── template-parts/        اسپرایت آیکون مشترک
└── assets/                همان css/js/fonts/img نسخه استاتیک، بدون تغییر
```
