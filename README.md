# وب‌سایت شرکتی پارس بلومولدینگ (Pars Blow Molding Technology)

قالب شرکتی راست‌چین برای یک سازنده ماشین‌آلات تزریق و بادی پلاستیک، طراحی‌شده با
اسکیل [`ui-ux-pro-max`](.claude/skills/ui-ux-pro-max) (الگوی طراحی: Trust & Authority + Conversion، سبک: Accessible & Ethical).

## ویژگی‌ها

- راست‌چین کامل (`dir="rtl"`) با فونت **Vazirmatn** (خودمیزبان، بدون وابستگی به CDN)
- رنگ سازمانی استخراج‌شده از لوگوی ارسالی (`#2b3691`) + طلایی به‌عنوان رنگ CTA
- حالت روشن/تاریک با یادآوری انتخاب کاربر (`localStorage`) و تشخیص خودکار ترجیح سیستم
- ناوبری کامل دسکتاپ (با مگامنوی محصولات) + منوی کشویی موبایل + نوار پایین اپلیکیشنی در موبایل
- اسلایدر هیرو با پخش خودکار، کنترل کیبورد/فوکوس، و پشتیبانی از `prefers-reduced-motion`
- بخش‌های: معرفی، ۵ دسته محصول، نمونه محصولات (با فیلتر)، خدمات ویژه (۵ آیکون)، بنر تماس، نوار اعتماد، فرم تماس
- انیمیشن‌های ورود هنگام اسکرول (Scroll reveal) و شمارنده‌های آماری

## ساختار پروژه

```
index.html              صفحه اصلی (تک‌صفحه‌ای)
assets/css/style.css    دیزاین‌سیستم و استایل‌ها (توکن‌های رنگ/تایپوگرافی/فاصله)
assets/js/main.js       تعامل‌ها: تم، منو، اسلایدر، فیلتر، اسکرول‌ریویل، شمارنده
assets/fonts/           فونت Vazirmatn (وزن‌های ۳۰۰ تا ۸۰۰) + مجوز OFL
assets/img/
  pars-icon.png          نماد لوگو (برش‌خورده از فایل ارسالی) — در هدر/فوتر/فاویکون
  pars-logo.png          لوگوی کامل ارسالی (آرم + وردمارک) برای استفاده‌های آینده
```

## اجرای محلی

نیازی به بیلد یا نصب پکیج نیست؛ فایل‌ها استاتیک هستند:

```bash
python3 -m http.server 8000
# سپس http://localhost:8000 را باز کنید
```

## نکات مهم برای تکمیل قالب

این نسخه یک **قالب آماده و کاملاً کارکردی** است، اما چون در این محیط اجرا دسترسی به
`www.pars-bm.com` مسدود بود (خطای `EGRESS_BLOCKED`)، امکان استخراج مستقیم متن‌ها و
منوهای سایت واقعی وجود نداشت. بنابراین:

1. **متن‌ها**: تمام متن‌ها (درباره ما، توضیح محصولات، خدمات و…) پیش‌نویس حرفه‌ای بر
   اساس ۵ محصولی است که خودتان نام بردید؛ پیشنهاد می‌شود قبل از انتشار با متن دقیق
   سایت فعلی مقایسه و جایگزین شوند. همه متن‌ها مستقیم داخل `index.html` هستند و
   جای‌به‌جایی آن‌ها ساده است.
2. **تصاویر محصولات/نمونه‌کارها**: چون دسترسی به عکس واقعی دستگاه‌ها ممکن نبود،
   به‌جای عکس از آیکون‌های خطی سفارشی (SVG) استفاده شده تا طراحی همچنان حرفه‌ای و
   یکدست بماند. برای جایگزینی با عکس واقعی: در `assets/img/products/` عکس را قرار
   دهید و در `product-card__art` / `sample-card__art` به‌جای تگ `<svg>`، تگ
   `<img>` بگذارید (کلاس‌های موجود را حفظ کنید).
3. **اطلاعات تماس** (آدرس، تلفن، ایمیل) در چند جا placeholder هستند — در
   `index.html` جستجو کنید: `021-88000000`, `info@pars-bm.com`, «تهران، شهرک صنعتی».
4. **فرم تماس** فعلاً با `mailto:` کار می‌کند (بدون بک‌اند). برای فرم واقعی، اکشن
   فرم را به سرویس مورد نظر (فرم‌اسپری، بک‌اند خودتان و…) وصل کنید.

## دسترسی‌پذیری و کارایی

مطابق چک‌لیست اسکیل `ui-ux-pro-max`: کنتراست رنگ ≥ 4.5:1، فوکوس‌رینگ قابل مشاهده،
دکمه‌ها با حداقل ۴۴×۴۴ پیکسل در موبایل، `prefers-reduced-motion` رعایت شده، و بدون
هیچ ایموجی به‌عنوان آیکون (همه آیکون‌ها SVG اختصاصی هستند).
